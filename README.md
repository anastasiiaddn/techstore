# TechStore — інтернет-магазин комп'ютерної техніки

Наскрізний проєкт з дисципліни «WEB-програмування».

Виконала: Анастасія Дудіна  
Варіант №1.

## Опис проєкту

TechStore — веб-застосунок для продажу комп'ютерної техніки. Сайт дозволяє переглядати каталог товарів, здійснювати пошук, фільтрацію та оформлювати замовлення.

## Стек технологій

HTML5, CSS3, Bootstrap 5, JavaScript, React, TypeScript, Node.js, Express, MySQL.

## Структура проєкту

- `src/` — клієнтська частина веб-застосунку.
- `docs/` — документація та макети сторінок.
- `labs/` — звіти з лабораторних робіт.
