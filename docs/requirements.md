
# Вимоги до проєкту TechStore

## 1. Призначення
TechStore — веб-застосунок для продажу комп'ютерної техніки. Користувачі можуть переглядати каталог, шукати товари, фільтрувати їх за категоріями та ціною, переглядати характеристики й оформлювати замовлення.

## 2. Ролі користувачів
- Відвідувач — перегляд каталогу, пошук товарів, оформлення замовлень.
- Адміністратор — додавання, редагування та видалення товарів, керування замовленнями.

## 3. Сутності предметної області
| Сутність | Атрибути |
|---|---|
| Category | id, name, slug |
| Item | id, category_id, name, price, description, in_stock |
| Order | id, customer_name, phone, email, created_at, status |
| OrderItem | id, order_id, item_id, qty, price |

## 4. Зв'язки між сутностями
- Category 1 — ∞ Item: одна категорія містить багато товарів.
- Order 1 — ∞ OrderItem: одне замовлення містить декілька позицій.
- Item 1 — ∞ OrderItem: один товар може входити до багатьох замовлень.

## 5. Сторінки веб-застосунку
1. `/` — головна сторінка: банер, новинки, популярні товари.
2. `/catalog` — каталог товарів із пошуком та фільтрацією.
3. `/item/:id` — картка товару з описом і характеристиками.
4. `/order` — форма оформлення замовлення.
5. `/contact` — контакти та зворотний зв'язок.

## 6. Функціональні вимоги
F1. Дані завантажуються асинхронно з сервера.

F2. Фільтрація товарів працює без перезавантаження сторінки.

F3. Форма замовлення перевіряє ім'я, телефон та електронну пошту.

F4. Адміністратор може додавати, змінювати та видаляти товари.

F5. Замовлення та інформація про товари зберігаються в реляційній базі даних.

## 7. Нефункціональні вимоги
N1. Адаптивний інтерфейс для екранів від 360 px.

N2. Lighthouse Performance — не менше 85 балів.

N3. Зручна навігація та зрозумілий інтерфейс.

N4. Підтримка сучасних браузерів Chrome, Firefox та Edge.
